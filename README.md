# Pakistan Air Quality Analysis and PM2.5 Prediction

## Overview

This project analyses air quality and weather data from five Pakistani cities: Lahore, Karachi, Islamabad, Peshawar, and Quetta. It uses exploratory data analysis, statistical testing, and machine learning to investigate PM2.5 pollution patterns and evaluate regression models.

## Objectives

* Compare PM2.5 levels across five cities.
* Examine monthly and seasonal pollution patterns.
* Analyse relationships between pollutants and weather variables.
* Apply statistical testing to compare pollution levels.
* Build and evaluate machine learning models for PM2.5 prediction.

## Tools

* Python
* Pandas and NumPy
* Matplotlib and Seaborn
* SciPy
* Scikit-learn
* Jupyter Notebook

## Methods

Data cleaning, datetime processing, feature engineering, exploratory data analysis, statistical testing, correlation analysis, Linear Regression, and Random Forest regression.

## Key Findings

* Lahore had the highest average PM2.5 concentration among the five cities in the analysed dataset.
* Quetta had the lowest average PM2.5 concentration.
* PM2.5 levels varied across cities and seasons.
* PM2.5 and PM10 showed a strong positive correlation.
* Model performance decreased when evaluated on a later time period.

**Source:** Kaggle
